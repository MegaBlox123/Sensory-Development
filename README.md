# Play & Learn — Demo

This is a small static demo that reproduces a hero section and a games/cards layout similar to the provided screenshots.

How to view locally:

1. Open the project folder in a code editor or file explorer.
2. Open `index.html` in your browser (double-click or use a local server).

Optional: serve using a simple local server:

```bash
# Python 3
python -m http.server 8000

# then open http://localhost:8000
```
